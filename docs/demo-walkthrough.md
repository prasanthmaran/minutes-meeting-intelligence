# Loom walkthrough outline (3–5 minutes)

1. Introduce the problem and scope in your own words (30 seconds).
2. Upload the sample, show processing, and explain whether the app is in demo or AI mode (30 seconds).
3. In AI mode, inspect decisions/actions, ask about the security review, and open its evidence citation (60 seconds).
4. Ask an unsupported question and show the actual behavior. Don't claim a refusal if the model fails (30 seconds).
5. Explain one architecture decision, one limitation, and one test that protects an important behavior (60 seconds).
6. Describe your AI-assisted workflow and one change you personally reviewed or corrected (30 seconds).

Before recording: configure a key locally, run the quality checklist, avoid displaying `.env`, capture the real application screens, and replace candidate-reflection prompts with your own observations. Automatic joining is a planned extension, not a feature to demonstrate.
